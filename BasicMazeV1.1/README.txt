Run in terminal exactly as you would any .py file

--CONTROLS--

After opening type 'start' to start

You will then be prompted to enter a grid size, this will create an n*n grid maze

Using arrow keys move your character (the @) through the maze to reach the end (the &)

Touching it ends the game and creates tells you the time it took to complete it

Type 'restart' to go again, otherwise close the terminal when you are done
